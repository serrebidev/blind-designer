# Credits

Blind Designer exists because color design is done by eye: pick a shade, tweak it, guess. For a blind designer that is a dead end. Palette extraction costs nothing here, and no color is ever guessed. Colors live in OKLCH, a perceptual color space, so schemes and complementary shades are predictable instead of eyeballed.

Third-party projects it uses:

- wxDragon (wxWidgets) for the interface.
- trypsynth's quiet-list for the palette. The license notice is at the end of the README.

OKLCH is a standard color space, not code from this project.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
